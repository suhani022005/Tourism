# Tourism Management System

A responsive multi-page tourism website designed to help users explore travel packages, view itineraries, and make bookings through a clean and interactive interface.

## 🌍 Problem Statement
Many travel websites lack clear navigation and structured package information, making it difficult for users to compare and plan trips efficiently.

## 🚀 Solution
This project provides a user-friendly tourism platform where users can browse tour packages, filter them by preferences, view detailed itineraries, and complete bookings smoothly.

## ✨ Key Features
- Fully responsive multi-page UI
- Tour package filtering by search, price range, and number of days
- Dynamic package and itinerary rendering using JavaScript
- Booking confirmation and feedback flow
- Dark/Light theme toggle
- Modern and clean UI design

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript

## 📌 Modules
- Home
- Packages
- Package Details
- Booking
- Contact
- Login
- Feedback
